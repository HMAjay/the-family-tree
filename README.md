# The Family Tree

Build your family tree from a blank page. Log in to save it or print it.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:43217](http://localhost:43217).

## What you can do

- **Start an empty tree** and add the first ancestor
- Connect parents, children, and spouses (other kin are inferred)
- **Save** or **Print** after you log in
- **Load saved** to bring back a tree stored on your account

## Accounts

Register with an email and password. Set `AUTH_SECRET` in production.
